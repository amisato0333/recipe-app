## このアプリを作った理由
料理人として働く兄から、「レシピをもっと管理しやすい方法があれば便利」という相談を受けたことが、このアプリを制作するきっかけでした。
日々増えていくレシピを分かりやすく整理し、必要なときにすぐ見つけられるアプリを目指して開発しています。

## 工夫した点
忙しい方や、スマートフォンやアプリの操作に慣れていない方でも迷わず利用できるよう、シンプルで直感的な画面構成を心掛けました。
必要な機能を分かりやすく配置し、誰でも使いやすいデザインを意識して制作しています。

## 使用技術
- HTML
- CSS
- JavaScript
- Git
- GitHub

## 現在実装している機能
- レシピ登録
- レシピ編集
- 写真管理
- 献立カレンダー
- バックアップ・復元

## 今後追加予定の機能
- AIに材料を入力すると献立を提案してくれる機能
- レシピが書かれた写真を読み込むと、AIが内容を自動で入力する機能（OCR・AI活用）
- お気に入り登録機能
- カロリー計算機能
- 栄養素の表示機能
